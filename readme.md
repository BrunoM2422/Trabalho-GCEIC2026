
# Projeto: Sistema de Cálculo de Custos para Construção de Piscinas

Este projeto tem como objetivo desenvolver uma aplicação completa para cálculo de custos relacionados à construção e manutenção de piscinas.


## O sistema será composto por:

- APIs desenvolvidas em Node.js
- Aplicação Web desenvolvida em React
- Testes unitários e funcionais
- Integração contínua e entrega contínua (CI/CD)

### O projeto deverá permitir cálculos relacionados a:

- Volume da piscina
- Custos de materiais elétricos
- Custos da parte hidráulica
- Custo da água utilizada
- Gasto mensal de manutenção
- Custos de mão de obra (MOB)

# Como executar o Projeto

## 1. Clone o projeto
```bash
  git clone https://github.com/BrunoM2422/Trabalho-GCEIC2026.git
```

## 2. Acesse a pasta
```bash
cd api-piscina
```
Instale as dependências:
```bash
npm install
```
```bash
node server.js
```
### A API está rodando em http://localhost:3000


## 3. Abra um novo terminal e acesse a pasta
```bash
cd app-piscina
```
Instale as dependências:
```bash
npm install
```
```bash
npm run dev
```
### Está rodando em  http://localhost:5173
