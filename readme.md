# Guia rápido para rodar o projeto

Abra um terminal novo e digite o seguinte:
cd api-piscina
npm install
node server.js

#Ele deve responder que a API agora está rodando em http://localhost:3000

Agora crie um novo terminal sem fechar o anterior e digite o seguinte:
cd app-piscina
npm install
npm run dev

#O link fornecido deve ser algo como http://localhost:5173. Apenas abra-o em seu navegador.
